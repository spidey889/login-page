> *"Every developer has that one project where everything started making sense — the late-night CSS tweaking, the excitement of watching a button actually do what you told it to, and the spark of building something from pure code."*

### ✨ A Trip Down Memory Lane

This login page is one of my earliest projects from back in **January 2026**. 

Before complex frameworks, endless dependencies, and heavy build setups, there was just:
- **`index.html`** — the skeleton.
- **`style.css`** — experimenting with that clean diagonal split-screen gradient and subtle typography.
- **`script.js`** — pure, vanilla JavaScript bringing the forms and micro-interactions (like ripple animations and client-side validation) to life.

### 💭 The Nostalgia

Building this was all about experimenting, learning the ropes, and feeling the magic of web development for the first time. It might look simple today, but back then, getting the form validation smooth and the layout pixel-perfect felt like building the next big thing.

Keeping this repo alive as a time capsule and a reminder of where the journey started.
